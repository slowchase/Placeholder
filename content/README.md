# Editable site content

This folder is the quick-edit area for the Highlight and Feeling Lost panels.

## Highlight
- Replace `highlight/photo.jpg` with a new image **using the same filename**. A portrait image works best because the card is 3:4.
- Edit `highlight/content.json` to change the displayed `name`, `description`, and image alt text.

## Feeling Lost
- Edit `feeling-lost/content.json`.
- `about.paragraphs` and `contact.paragraphs` are lists of paragraphs.
- `faq.items` contains question/answer pairs. You can edit, remove, or add items while keeping the JSON punctuation valid.

After committing an updated file to GitHub, GitHub Pages will serve the new content automatically. No changes to `index.html` are required.
